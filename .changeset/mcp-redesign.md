MCP got a full redesign. Settings › MCP has two views. Yours is one list of every server (yours, claude.ai, plugins) where each server can reconnect from its own row. Discover finds servers from claude.ai, Claude Code, Codex, opencode and the official MCP registry, and adds them in one click. Each server has a details drawer for its tools, sign-in and logs. The composer's + menu now has an MCP submenu that turns servers on or off for just that chat. claude.ai connectors, including ones your org shares, now run natively in Claude sessions with their real sign-in state. And when several servers need sign-in, the chat shows one banner with "+N more" instead of a stack.
